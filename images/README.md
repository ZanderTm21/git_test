# Images

Drop files here using these exact names. Until a file is added, the site shows its name in a placeholder.

| File | Where it appears | Suggested size |
|---|---|---|
| `logo.png` | Header (transparent PNG; replaces the text logo automatically) | ~400px wide |
| `hero.jpg` | Full-screen hero background | 1600×2000 (portrait works best on mobile) |
| `project-1-before.jpg` / `project-1-after.jpg` | Before & after slider 1 | 1200×900 |
| `project-2-before.jpg` / `project-2-after.jpg` | Before & after slider 2 | 1200×900 |
| `project-3-before.jpg` / `project-3-after.jpg` | Before & after slider 3 | 1200×900 |
| `finance-bg.jpg` | "Spread the cost" background | 1600×1000 |
| `cta-bg.jpg` | Final call-to-action background | 1600×1000 |

The before and after photos in each pair should be taken from the same angle so the slider lines up.
